## Версия 0.2.5

Слева внизу — компактная капсула с иконками пяти разделов; справа — крупная кнопка «Ещё» с профилем, настройками, обновлениями и выходом.
Все элементы шапки расположены в один горизонтальный ряд. Под шапкой — отдельная узкая полоса вкладок с иконками и текстом.
Свайпы, локальный архив и плавающие кнопки сохранены. Группы, каналы и сообщества пока готовятся.

Обновления: Ещё → Обновления. Подпись совместима с Pulse 0.2.0–0.2.4; установку подтверждает Android.

Для общения запустите Pocket Server. На том же телефоне в Pulse укажите `http://127.0.0.1:8080`; на других телефонах в той же доверенной Wi-Fi сети — адрес из Pocket Server. Зарегистрируйте аккаунты и создайте переписку.

Тестовая версия: все комнаты общие, HTTP не шифрует трафик.
