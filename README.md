## Версия 0.3.1

В ленте убрана карточка «В ленте пока тихо». Вместо неё — секция «Рекомендации» с овальными фильтрами Все / Люди / Группы / Каналы / Сообщества.
Новый порядок: истории → рекомендации → «Что сегодня у вас?» → новости. Кнопка создания поста переводит фокус в новое место поля.
Реальные подборки рекомендаций пока не подключены; категории показывают честные пустые состояния.

Нижнее меню: Главная / Чаты / Контакты / Профиль. В главной — Лента / Группы / Каналы / Сообщества. «Ещё» в шапке открывает профиль, настройки, обновления и выход.
Контакты локальные. Посты и истории — локальные черновики. Группы, каналы и сообщества пока готовятся.

В чатах есть аудио/видео кнопки и демоэкраны звонков. Принять — свайп вправо, отклонить или отменить — влево. Реальной передачи звука/видео и входящих вызовов на другой телефон нет. Входящий макет можно проверить кнопкой на исходящем экране. UI-тесты жестов проходят в CI.

Обновления: Ещё → Обновления. Подпись совместима с Pulse 0.2.0–0.3.0; установку подтверждает Android.
Для переписки запустите Pocket Server: на том же телефоне укажите `http://127.0.0.1:8080`, на других в доверенной Wi-Fi сети — адрес из Pocket Server.
Тестовая версия: все комнаты общие, HTTP не шифрует трафик.
