# Pulse — APK и обновления

[Скачать Pulse 0.3.2](https://raw.githubusercontent.com/dozyFJ/pulse-updates/main/releases/pulse-0.3.2.apk)

[Скачать Pocket Server](https://raw.githubusercontent.com/dozyFJ/pulse-updates/main/pulse-pocket-server.apk)

В Pulse 0.3.2 обновлён экран предпросмотра звонка: тулбар с отменой и сворачиванием, карточка с аватаром слева и данными справа. Свернутую плашку можно развернуть без сброса состояния. Принятие — свайп вправо; отклонение и отмена — влево.

В ленте под историями — рекомендации с фильтрами «Все», «Люди», «Группы», «Каналы», «Сообщества»; ниже — «Что сегодня у вас?».

Звонки пока демонстрационные: другой пользователь не получает вызов, аудио/видео не передаются. Фото и данные в экране звонка задаются локально для предпросмотра. Посты и истории — локальные черновики; рекомендации, группы, каналы и сообщества пока без сервера.

Обновление: в Pulse откройте «Ещё → Обновления». Android запросит разрешение на установку APK. Манифест версии: [latest.json](latest.json). Исходники в этом репозитории не публикуются.
