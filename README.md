## Версия 0.2.7

Вкладки под шапками удалены. Вместо них — секции на каждой странице.
Главная: «Что сегодня у вас?» с полем поста и предпросмотром; секция «Лента» с горизонтальным рядом квадратных карточек историй с обводкой; затем пустое состояние публикаций и «Новости».
Пост и история сохраняются как локальные черновики, отдельно для аккаунта и сервера. Общая публикация и загрузка фото пока не подключены; в интерфейсе это явно указано.
Сообщения: секции Входящие / Переписки / Архив. Настройки: Аккаунт / Подключение / Обновления. Удерживайте переписку для архивации или возврата.
«Ещё» остаётся в основной шапке, снизу — капсула с иконками разделов. Плавающая кнопка на главной переводит фокус в поле поста.
Группы, каналы и сообщества пока готовятся.

Обновления: Ещё → Обновления. Подпись совместима с Pulse 0.2.0–0.2.6; установку подтверждает Android.

Для общения запустите Pocket Server. На том же телефоне укажите в Pulse `http://127.0.0.1:8080`; на других телефонах в той же доверенной Wi-Fi сети — адрес из Pocket Server. Зарегистрируйте аккаунты и создайте переписку.

Тестовая версия: все комнаты общие, HTTP не шифрует трафик.
