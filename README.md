## Версия 0.2.8

Стиль по визуальному референсу: объёмные шапки-капсулы с тонкой обводкой, круглые действия, округлые карточки переписок, графитовые поверхности и сохранённый синий акцент.
Создание переписки, предпросмотр поста и редактор черновика истории открываются в панелях снизу с округлёнными углами и большими кнопками.

Вкладки под шапками не возвращены. Главная остаётся секциями: поле «Что сегодня у вас?», истории, лента, новости. Сообщения и настройки тоже состоят из секций.
Посты и истории пока сохраняются как локальные черновики. Общая публикация и загрузка фото не подключены. Группы, каналы и сообщества пока готовятся.

Обновления: Ещё в шапке → Обновления. Подпись совместима с Pulse 0.2.0–0.2.7; установку подтверждает Android.

Для общения запустите Pocket Server. На том же телефоне в Pulse укажите `http://127.0.0.1:8080`; на других телефонах в той же доверенной Wi-Fi сети — адрес из Pocket Server. Зарегистрируйте аккаунты и создайте переписку.

Тестовая версия: все комнаты общие, HTTP не шифрует трафик.
