# Pulse — APK и обновления

[Скачать Pulse 0.3.4](https://raw.githubusercontent.com/dozyFJ/pulse-updates/main/releases/pulse-0.3.4.apk)

[Скачать Pocket Server](https://raw.githubusercontent.com/dozyFJ/pulse-updates/main/pulse-pocket-server.apk)

В Pulse 0.3.4 подразделы групп, каналов и сообществ оформлены горизонтальными переключателями-пилюлями. Ниже показывается только выбранный подраздел.

Обновлён экран предпросмотра звонка: тулбар с отменой и сворачиванием, карточка с аватаром слева и данными справа. Свернутую плашку можно развернуть без сброса состояния. Принятие — свайп вправо; отклонение и отмена — влево.

Главное меню под основной шапкой теперь оформлено отдельными текстовыми пилюлями «Главная / Чаты / Контакты / Профиль», как вкладки «Лента / Группы». Вкладки «Лента / Группы / Каналы / Сообщества» переключаются горизонтальными свайпами. В ленте остались истории и рекомендации; блок «Что сегодня у вас?» и новости убраны. Карандаш открывает редактор локального черновика.

Звонки пока демонстрационные: другой пользователь не получает вызов, аудио/видео не передаются. Фото и данные в экране звонка задаются локально для предпросмотра. Посты и истории — локальные черновики; рекомендации, группы, каналы и сообщества пока без сервера.

Обновление: в Pulse откройте «Ещё → Обновления». Android запросит разрешение на установку APK. Манифест версии: [latest.json](latest.json). Исходники в этом репозитории не публикуются.
