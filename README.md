## В версии 0.2.3

Левая панель занимает всю высоту приложения, без капсулы и внешних отступов.
Всё содержимое страниц — шапки, вкладки, списки и плавающие кнопки — находится справа.
В панели: иконки с подписями, прокрутка, бургер с профилем, настройками, обновлениями и выходом.
Основные разделы листаются вверх/вниз; вкладки внутри разделов — влево/вправо.
На главной показаны логотип Pulse, версия, имя и @ник аккаунта.
Сообщения: Все / Входящие / Архив. Удерживайте переписку для архивации или возврата.
Архив и прочтение локальные, отдельно для аккаунта и сервера.
Группы, каналы и сообщества пока готовятся.

## Подключение

Запустите Pocket Server. В Pulse на этом же телефоне укажите `http://127.0.0.1:8080`.
Другие телефоны в той же доверенной Wi-Fi сети используют адрес из Pocket Server.
Зарегистрируйте аккаунт и создайте переписку.

Обновления: бургер → Обновления. Подпись совместима с Pulse 0.2.0–0.2.2.
Установку подтверждает Android; скрытая установка и принудительный перезапуск не поддерживаются.

Тестовая версия: все комнаты общие, HTTP не шифрует трафик.
