## Версия 0.3.0

- Нижнее меню: Главная / Чаты / Контакты / Профиль.
- Внутри главной: Лента / Группы / Каналы / Сообщества. Все / Черновики убраны из ленты. Поле «Что сегодня у вас?» находится под историями.
- Основная шапка — скруглённый прямоугольник, без имени аккаунта и версии; «Ещё» остаётся в шапке.
- В шапке переписки — аудио- и видеозвонок. Они открывают только ПРЕДПРОСМОТР экранов: исходящий, входящий, принятие, отклонение и отмена.
- Принятие — потянуть зелёную кнопку слева направо. Отклонение и отмена — красную справа налево. Неполный жест возвращается в исходное положение.
- Круглый аватар, имя, тег и номер на экране вызова. Непредоставленные данные не выдумываются. Фото и данные можно задать для предпросмотра, не меняя профиль.
- Контакты сохраняются вручную на устройстве отдельно для аккаунта и сервера.

Это экраны для проверки дизайна. Другой пользователь не получает вызов; передача звука/видео, камера, микрофон и входящие уведомления не подключены.
Для проверки входящего нажмите кнопку «Проверить входящий вызов» на исходящем экране.
UI-тесты проверяют направления жестов, возврат короткого жеста и однократность действия.

Посты и истории пока локальные черновики. Группы, каналы и сообщества пока готовятся.
Обновления: Ещё → Обновления. Подпись совместима с Pulse 0.2.0–0.2.9; установку подтверждает Android.

Для переписки запустите Pocket Server. На том же телефоне укажите `http://127.0.0.1:8080`; на других телефонах в той же доверенной Wi-Fi сети — адрес из Pocket Server.
Тестовая версия: все комнаты общие, HTTP не шифрует трафик.
