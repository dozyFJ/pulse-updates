# Pulse — APK для Android

- [Скачать Pulse](https://github.com/dozyFJ/pulse-updates/raw/refs/heads/main/pulse.apk)
- [Скачать Pocket Server](https://github.com/dozyFJ/pulse-updates/raw/refs/heads/main/pulse-pocket-server.apk)

Прямые APK без ZIP и без входа в GitHub. Исходный код хранится отдельно.

## Подключение

Запустите Pocket Server. В Pulse на этом же телефоне укажите `http://127.0.0.1:8080`.
На другом телефоне в той же Wi-Fi сети используйте адрес из Pocket Server.
Зарегистрируйте аккаунт и создайте комнату.

## Обновления

Pulse 0.2.0 умеет проверять версии в Настройки → Обновления, скачивать и проверять APK.
Установку подтверждает Android. Используется постоянный ключ подписи для новых версий.
Старые тестовые APK подписывались случайными debug-ключами и могут потребовать однократной переустановки клиента.
Pocket Server удалять не нужно: его база с аккаунтами и перепиской отдельная.

Тестовая версия: все комнаты общие, HTTP не шифрует трафик. Используйте доверенную сеть.
