## Версия 0.2.2

Левый вертикальный сайдбар с иконками, подписями и прокруткой. Бургер: профиль, настройки, обновления, выход.
Основные разделы листаются вверх/вниз; вкладки внутри разделов — влево/вправо.
У каждого раздела своя шапка, вкладки под ней и плавающая кнопка действия.
На главной сверху логотип Pulse, версия, имя и @ник текущего аккаунта.
Сообщения: Все / Входящие / Архив. Удерживайте переписку для архивации или возврата.
Архив и прочтение локальные, отдельно для аккаунта и сервера.

Группы, каналы и сообщества пока готовятся; их кнопки показывают уведомление об этом.

## Подключение и обновления

Запустите Pocket Server. В Pulse на этом же телефоне укажите `http://127.0.0.1:8080`.
Другие телефоны должны находиться в той же доверенной Wi-Fi сети и использовать адрес из Pocket Server.
Зарегистрируйте аккаунт и создайте переписку.

Новые версии — бургер → Обновления. Подпись совместима с Pulse 0.2.0 и 0.2.1.
Android запрашивает подтверждение установки. Скрытой установки и принудительного перезапуска нет.

Тестовая версия: все комнаты общие, HTTP не шифрует трафик.
