# Pulse — Android APK

- [Скачать Pulse 0.2.4](https://raw.githubusercontent.com/dozyFJ/pulse-updates/main/releases/pulse-0.2.4.apk)
- [Скачать Pocket Server](https://raw.githubusercontent.com/dozyFJ/pulse-updates/main/pulse-pocket-server.apk)

Прямые APK без ZIP и входа в GitHub. Исходники хранятся отдельно.

В 0.2.4 — плоская нижняя навигация на всю ширину, с иконками и подписями. Без капсулы, теней и отдельной боковой панели. Активный раздел выделен синим. Бургер с профилем, настройками, обновлениями и выходом находится в шапке.
Шапки, вкладки, свайпы, локальный архив и плавающие кнопки сохранены.
Группы, каналы и сообщества пока готовятся.

Обновления: бургер → Обновления. Подпись совместима с Pulse 0.2.0–0.2.3; установку подтверждает Android.

Для общения запустите Pocket Server. На том же телефоне укажите в Pulse `http://127.0.0.1:8080`; на других телефонах в той же доверенной Wi-Fi сети — адрес из Pocket Server. Зарегистрируйте аккаунты и создайте переписку.

Тестовая версия: все комнаты общие, HTTP не шифрует трафик.
