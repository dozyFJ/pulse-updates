## Версия 0.2.9

В секциях появились отдельные овальные фильтры в стиле Recents / Missed: выбранная кнопка залита синим, остальные тёмные с тонкой светлой обводкой. Ряд прокручивается горизонтально.
Сообщения: Все / Входящие / Архив. Выбор действительно фильтрует переписки, архивация и возврат — удержанием карточки.
Лента: Все / Черновики. В Черновиках доступен сохранённый пост и его предпросмотр.
Разделы групп, каналов и сообществ имеют такие же фильтры секций, но их серверные функции пока готовятся.
Секции, шапки-капсулы, нижняя навигация и меню «Ещё» в основной шапке сохранены.

Посты и истории пока локальные черновики; общая публикация и загрузка фото не подключены.
Обновления: Ещё → Обновления. Подпись совместима с Pulse 0.2.0–0.2.8; установку подтверждает Android.

Для общения запустите Pocket Server. На том же телефоне в Pulse укажите `http://127.0.0.1:8080`; на других телефонах в той же доверенной Wi-Fi сети — адрес из Pocket Server. Зарегистрируйте аккаунты и создайте переписку.

Тестовая версия: все комнаты общие, HTTP не шифрует трафик.
