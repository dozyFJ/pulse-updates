## Версия 0.2.6

«Ещё» находится в основной шапке и открывает профиль, настройки, обновления и выход.
Внизу слева — компактная капсула только с иконками разделов.
Вкладки внутри каждой родительской страницы — одна плоская полоса с синей линией выбора, без отдельных скруглённых кнопок.
Главная имеет собственные вкладки Лента / Новости; Сообщения — Все / Входящие / Архив. Выбор каждой страницы сохраняется независимо.
Свайпы, локальный архив и плавающие кнопки сохранены. Группы, каналы и сообщества пока готовятся.

Обновления: Ещё в шапке → Обновления. Подпись совместима с Pulse 0.2.0–0.2.5; установку подтверждает Android.

Для общения запустите Pocket Server. На том же телефоне в Pulse укажите `http://127.0.0.1:8080`; на других телефонах в той же доверенной Wi-Fi сети — адрес из Pocket Server. Зарегистрируйте аккаунты и создайте переписку.

Тестовая версия: все комнаты общие, HTTP не шифрует трафик.
